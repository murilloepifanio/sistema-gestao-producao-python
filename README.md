# SGPI - Sistema de Gestão de Produção Industrial

Sistema de Gestão de Produção Industrial desenvolvido em Python como projeto de estudo.

O objetivo do projeto é aplicar conceitos de programação na criação de um sistema simples para gerenciamento de produtos, produção, vendas e estoque.

## Funcionalidades

- Cadastro de produtos
- Registro de produção
- Registro de vendas
- Consulta de estoque
- Controle de receita
- Relatórios básicos
- Área para gerenciamento de funcionários

## Conceitos utilizados

- Funções
- Parâmetros e argumentos
- Listas
- Dicionários
- Estruturas condicionais
- Laços `for` e `while`
- `enumerate()`
- Entrada de dados com `input()`
- Conversão de tipos
- Manipulação de dados em memória

## Como executar

É necessário ter o Python instalado.

Execute o arquivo:

```bash
python sgpi.py
